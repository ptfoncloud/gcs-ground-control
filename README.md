# GCS Mission Operations Console

Full-stack flight control, telemetry ingestion, and Leap Motion hand-tracking ground station.

## Architecture
- **Backend:** FastAPI, PyMAVLink, SQLAlchemy (SQLite), Asyncio WebSockets
- **Frontend:** Vue 3, Pinia, Leaflet, Vite
- **Integrations:** ArduPilot SITL, Leap Motion Controller
